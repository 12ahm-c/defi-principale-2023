# Caméra de la Vérité — Vérité Climat

Application SPA (React + Vite + TypeScript + Tailwind CSS) pour vérifier des affirmations climatiques
à partir de sources scientifiques officielles (IPCC, ADEME, HCC, Réseau Action Climat, Transitions 2050).

## Technologies

- React 18 + Vite + TypeScript + Tailwind CSS
- Zero-runtime backend (moteur de données côté client, fichiers JSON locaux)

## Installation et lancement

```bash
npm install
npm run dev
npm run build
npm run typecheck
```
